# 텍스트 뱅가드: 게임 기획 개요

## 1. 메인 타이틀 흐름
- 초기 화면에 게임 제목과 버튼 4개를 표시: **스토리 모드**, **무한 모드**, **무한 모드 기록**, **옵션**.
- 스토리/무한 모드 버튼을 누르면 즉시 게임이 시작되어 메인 타이틀을 벗어남.
- 무한 모드 기록에서는 언제든 메인 타이틀로 복귀 가능.
- 스토리/무한 모드 종료 시 메인 타이틀로 복귀.

## 2. 모드 공통 진행 구조
- 시작 시 플레이어 자금 $100 지급 후 **소환** 단계 진입.
  - 첫 소환에서는 반드시 뱅가드 ≥ 1장 구매 가능하도록 카드 풀과 가격을 강제 조정.
- 스테이지 사이클: `일반 스테이지 ×3 → 보스 스테이지 ×1`을 반복.
  - 사이클 2회마다 **재정비 스테이지**가 열려, 저장된 키워드 부여 카드를 사용해 뱅가드에 키워드를 부여.
  - 재정비 종료 후 다시 사이클 반복.
- 전장: 플레이어 측 3×3 배치 그리드.
  - 모드 첫 턴에는 뱅가드 최소 1장 배치 필요. 전장이 전멸하면 게임 종료.

## 3. 스테이지 종류
### 일반 스테이지
- 등장: **일반 엔티티**.
- 엔티티 기본 요소: 체력, 물리/특수 공격력·방어력, (사거리 없음), 위협력.
- 엔티티명·종족 무작위, 키워드 무작위(키워드 설명의 대상이 "뱅가드"로 치환).
- UI: 현재 공격 범위와 다음 공격 범위를 두 슬롯으로 표시. 실제 범위는 필드의 뱅가드 배치 상태를 기준으로 무작위 선택하며 개수는 위협력 수치와 동일.
- 처치 보상: 소량의 돈(스케일링), 25% 확률로 **키워드 부여 카드**(재정비 전용) 획득.

### 보스 스테이지
- 등장: **보스 엔티티**.
- 일반 엔티티 대비 능력치 배수 강화 + 키워드 1개 이상 확정, 위협력이 더 높음.
- 처치 보상: 대량의 돈(스케일링) + 무작위 키워드 부여 카드 1장 이상 확정(저확률로 2장 이상).
- 보스 스테이지 종료 시 **계약** 1종 선택: 4개 안 중 하나를 골라 전체 아군에게 영구 버프와 함께 디버프를 부여.

### 재정비 스테이지
- 소지한 키워드 부여 카드를 선택해 뱅가드에 적용.
- 스테이지 완료 후 다음 사이클 진행.

## 4. 턴 진행
- **플레이어 턴**
  - 게이트(인벤토리)에서 뱅가드/택틱 카드 사용.
  - 배치된 뱅가드의 위치 변경: 상하좌우 1칸 교환당 기본 $2(스케일링). 같은 턴에 새로 배치한 뱅가드는 무료 이동 및 배치 취소 가능.
  - 제한 시간 존재, 플레이어가 조기 종료 가능.
- **엔티티 턴**
  - 표시된 공격 범위에 따라 공격 실행.
- 위 순서가 1턴.

## 5. 전투/능력치 규칙
- 피해 계산: 물리/특수 피해를 각각 (공격력−방어력)으로 계산해 더함. 모든 연산은 올림 처리.
- 기본 크리티컬: 5% 확률로 2배 피해, **울트라 크리티컬** 1% 확률로 4배 피해.
- 배치된 뱅가드는 스테이지 진행으로 스케일링되지 않음.

## 6. 소환 시스템
- 소환 시 무작위 카드 6장 제시 (뱅가드:택틱 등장 비율 평균 5:3, 뱅가드는 최소 1장 보장).
- **재소환(리롤)**: 추가 비용(기본 $5, 진행도 및 리롤 횟수에 따라 스케일 증가).
- 구매 가격은 카드 파워를 수식으로 산출(기본 요소 + 키워드 반영).
- 뱅가드 카드는 배치 후 기능 발동, 배치 전에는 효과 없음.
- 배치된 뱅가드는 희생(판매) 가능: 구매 비용의 30% 회수. 같은 턴에는 배치 취소 가능.

## 7. 뱅가드 카드 사양
- 표시 정보: 명칭(최대 7자 한글 랜덤), 역할군(전방/중간/후방: 기본 요소 기반 계산), 종족(인간/짐승/기계/정령/괴물/저주, 드물게 다중 종족), 사거리(1~3), 기본 요소(체력, 물리/특수 공격·방어).
- 일부는 키워드를 지닌 채 등장할 수 있음.
- 체력이 0 이하가 되면 처치되어 카드 소멸(특수 키워드 예외).

## 8. 엔티티/보스 스케일링
- 모든 엔티티 능력치는 스테이지 진행도에 따라 스케일링.
- 최초 등장 엔티티는 초반 뱅가드보다 약하게 설정.

## 9. 키워드 목록(예시)
- 전사의심장: 체력 50% 이하 시 물리 공격력 n% 상승.
- 전사의투기: 체력 50% 이하 시 물리 공격력 n 상승.
- 전사의담력: 체력 50% 이하 시 물리 방어력 n% 상승.
- 전사의정신: 체력 50% 이하 시 물리 방어력 n 상승.
- 마법의심장: 체력 50% 이하 시 특수 공격력 n% 상승.
- 마법의투기: 체력 50% 이하 시 특수 공격력 n 상승.
- 마법의담력: 체력 50% 이하 시 특수 방어력 n% 상승.
- 마법의정신: 체력 50% 이하 시 특수 방어력 n 상승.
- 회복술사: 턴 종료마다 사거리 내 아군 체력 n 회복.
- 끈질김: 치명 피해 시 체력 1로 생존 후 키워드 제거.
- 부활: 처치 시 게이트로 귀환 후 키워드 제거.
- 도발: 자신이 받는 피해 n% 증가, 아군 피해 m% 감소.
- 보스슬레이어: 보스에게 가하는 피해 n% 증가.
- 미니언슬레이어: 일반 엔티티에게 가하는 피해 n% 증가.
- 천상의보호막: 피해 무시 확률 n%.
- 위세강화/격투단련/경질화/집중력강화/정신단련: 턴 종료마다 해당 능력치 n 증가.
- 위압: 피해를 입힌 엔티티의 물리 방어력 n% 감소.
- 패기: 피해를 입힌 엔티티의 특수 방어력 n% 감소.
- 카리스마: 사거리 내 아군의 대미지 n% 증가.
- 임기응변: 피해 시 n% 확률로 체력 n 회복.
- 흡혈: 입힌 피해의 n%만큼 체력 회복.
- 분노/전투심리: 동일 엔티티 대상 피해량 n% 증가(대상 변경 시 초기화).
- 전문가: 크리티컬 확률 n% 증가.

## 10. 택틱 카드 목록
- 밴드: 뱅가드 체력 최대치의 25% 회복. 기본 $5.
- 메드킷: 뱅가드 체력 최대치의 50% 회복. 기본 $10.
- 신의눈물: 뱅가드 체력 전량 회복. 기본 $15.
- 고무: 이번 턴 모든 뱅가드 피해 +20%. 기본 $20.
- 파이어볼: 엔티티 체력의 20% 피해. 기본 $25.
- 자극제: 이번 턴 특정 뱅가드 피해 +100%. 기본 $15.
- 에너지가드: 이번 턴 최전방 뱅가드 무적. 기본 $30.
- 약점파악: 이번 턴 모든 뱅가드 크리티컬 확률 +20%. 기본 $15.
- 승리의함성: 이번 스테이지 모든 뱅가드 피해 +20%. 기본 $40.

## 11. 모드별 클리어 조건
- **스토리 모드**: 보스 스테이지 19회 진행 후 20번째에 최종 보스 등장. 최종 보스 격파 시 게임 종료 및 승리.
- **무한 모드**: 무한 반복 진행, 무한 모드 기록 화면에서 스테이지 기록 확인 가능.

## 12. 초기 값 및 스케일링 원칙
- 모든 연산은 올림 적용.
- 첫 등장 뱅가드 기본 능력치는 평균 약 10(각 수치 기준).
- 첫 등장 엔티티는 초기 뱅가드보다 약함.

## 13. 최종 보스 사양(아키리히치)
- 종족: 초월자(전용).
- 기본 능력치(스케일링 전): 체력 200 / 물리 공격력 200 / 물리 방어력 200 / 특수 공격력 200 / 특수 방어력 200 / 위협력 5.
- 키워드 **모든것을초월한자**:
  - 체력 75% 이하: 물리/특수 방어력 +25%.
  - 체력 50% 이하: 체력 전량 회복, 물리/특수 공격력 +25%, 위협력 7.
  - 체력 25% 이하: 위협력 9, 체력·위협력 제외 모든 능력치 +25%.

본 문서는 핵심 규칙을 구조화하여 설계 및 구현 시 빠르게 참조할 수 있도록 정리한 개요이다.
